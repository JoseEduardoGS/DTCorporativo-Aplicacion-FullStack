\# Sistema Integrado para Planta Trituradora



Proyecto full-stack de portafolio: sistema de gestión integral (producción,

inventarios, ventas, finanzas y nómina) para una planta trituradora.



\## Estado del proyecto

\- \[x] Fase 0 — Inicialización del proyecto

\- \[ ] Módulo 1 — Usuarios, roles, permisos y auditoría

\- \[ ] Módulo 2 — Catálogos: Materiales y Máquinas

\- \[ ] Módulo 3 — Producción, bitácora y consumo de diésel

...



\## Stack

\- Frontend: Next.js + TypeScript

\- Backend: Node.js + Express + TypeScript

\- Base de datos: PostgreSQL
